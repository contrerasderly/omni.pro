# 🧪 Automatización de App Móvil

## 🧰 Requisitos previos instalados

Node.js y npm → https://nodejs.org/
Java JDK (v11+) → Necesario para Android SDK
Android Studio + Android SDK (para emulador o dispositivo físico)

## Appium CLI:
npm install -g appium

## Appium Doctor (para verificar dependencias):
npm install -g appium-doctor
appium-doctor

## 📁 Crear el proyecto con WebdriverIO

npm init -y

Configurar el archivo wdio.conf.js
